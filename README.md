## 📖 نبذة عن المنصة
**منصة الرائد التعليمية الذكية** هي بيئة تعليمية تفاعلية متكاملة وشاملة، صُممت وفق أعلى المعايير البيداغوجية والتقنية لتخدم معلمي وطلاب الرياضيات في مختلف المراحل التعليمية (المرحلة الابتدائية، المتوسطة، والثانوية).

تعتمد المنصة نمطاً بصرياً عصرياً فائق الدقة مستوحى من كبرى المنصات التعليمية العالمية (**Khan Academy, Brilliant.org, ومنصة مدرستي**)، وتعمل كلياً كـ **Single Page Application (SPA)** ثابتة وخفيفة دون الحاجة لأي خوادم معقدة، مما يجعلها مهيأة للاستضافة الفورية والمجانية عبر **GitHub Pages**.

---

## 🎯 الضوابط الرياضية والتربوية المعتمدة بالمنصة
1. **نظام الفصلين الدراسيين المعتمد:** توزيع كامل ودقيق للدروس والفصول على (الفصل الدراسي الأول والفصل الدراسي الثاني) بما يتوافق مع أحدث خطط وزارة التعليم بالمملكة.
2. **الأرقام العربية المشرقية الأصيلة (٠، ١، ٢، ٣، ٤، ٥، ٦، ٧، ٨، ٩):** التزام تام بالأرقام العربية المعتمدة رسمياً في المناهج السعودية مع حظر الأرقام الغربية داخل نصوص ومسائل المنهج.
3. **التمثيل الصحيح للقوى والأُسُس الرياضية:** رفع الأس إلى **أعلى يسار الأساس** بشكل متقن ومحكم للأعداد والمتغيرات (مثل $س^٢$ و $٢^٥$ و $١٠^٤$) وفق القواعد الرياضية العربية المعتمدة، مع حظر الرموز الدخيلة كرمز الـ Caret (`^`).
4. **التدقيق الرياضي المتخصص:** مراجعة وحل كافة المسائل والمعادلات والمتباينات الجبرية والعمليات الحسابية بدقة متناهية، مع شروحات وتفسيرات رياضية خطوة بخطوة لكل تمرين.
5. **نموذج التعلم الخماسي (5Es):** بناء كل درس وفق مراحل (التهيئة والانخراط Engage، الاستكشاف Explore، الشرح والتفسير Explain، التوسع والتعميق Elaborate، التقويم Evaluate).

## 🚀 المكونات والأنظمة الرئيسية

### ١. 🎯 مركز الدرس التفاعلي (Lesson Cockpit)
- يشمل **٧٦ درساً شاملاً** يغطي المناهج الدراسية (الصف السادس الابتدائي، الأول المتوسط، الثالث المتوسط، والأول الثانوي).
- ترويسة معيارية متكاملة لكل درس (نواتج التعلم، المفردات، أرقام صفحات الكتاب المدرسي، وشارات الإنجاز).
- خطة التدريس STEM الخماسية المتكاملة مع الأنشطة الصفية والزمن المقترح.
- ملخص بصري ومطوية مفاهيم قابلة للطباعة والمراجعة السريعة.
- ورقة عمل استقصائية مخصصة لكل درس مع أسئلة مهارات التفكير العليا.

### ٢. 🏛️ منصة سقراط الحوارية الذكية
- بيئة توليد حوارية تفاعلية تحاكي المنهج السقراطي في تدريس الرياضيات.
- قيادة الطالب لاكتشاف القواعد الرياضية ذاتياً من خلال الأسئلة الاستقصائية المتدرجة ومعالجة التصورات البديلة والأخطاء الشائعة.

### ٣. 🏦 بنك الأسئلة الشامل الموحد
- يضم أكثر من **١٦٤٠ سؤالاً مقنناً** تشمل:
  - أسئلة الاختيار من متعدد (MCQ) مع ٤ خيارات مدروسة بدقة وتفسير رياضي للحل الصحيح.
  - أسئلة الصواب والخطأ (T/F) مع تصحيح العبارات الخاطئة.
  - الأسئلة المقالية وأوراق العمل التطبيقية.
- إمكانية التصفية الفورية حسب الصف، الفصل الدراسي، الباب، ونوع السؤال، مع ميزة الإضافة السريعة لسلة الاختبار.

### ٤. 📝 منشئ الاختبارات الوزاري المتقدم (Exam Builder)
- إنشاء الاختبارات الفترية والنهائية بنقرة زر واحدة أو بالاختيار المخصص.
- **تصدير مستند Word رسمي (.docx):**
  - ترويسة رسمية وشعار وزارة التعليم وشعار المدرسة.
  - جداول RTL متناسقة، مساحات إجابة مقننة، نماذج إجابة ملحقة، وجداول تصحيح ورصد الدرجات.
- **تصدير مستند PDF وطباعة فورية:** تنسيق طباعي احترافي جاهز للتوزيع على الطلاب فوراً.
- إمكانية نسخ الأسئلة بصيغة Rich Text ولصقها مباشرة في برامج أوفيس.

### ٥. 🛠️ الأدوات والمختبر التفاعلي الذكي
- مختبر تفاعلي مدمج لكل درس يدعم برمجيات الهندسة الديناميكية (GeoGebra، النماذج الخطية، خطوط الأعداد التفاعلية، وشبكات الإحداثيات).

### ٦. 🎨 واجهة مستخدم فائقة التميز (UI/UX)
- خطوط عربية حديثة وعالية المقروءة (`Readex Pro` و `Cairo`).
- دعم سلس ومريح للعين بين **الوضع الليلي (Dark Mode)** و**الوضع النهاري (Light Mode)**.
- محرك بحث شجري فائق السرعة مع دعم الاختصار العالمي `Ctrl + K`.

## 🌐 خطوات الاستضافة والنشر على GitHub Pages

المنصة مبنية كصفحة ويب ثابتة (Static Web App) خالية من أي اعتماديات خلفية، مما يتيح تشغيلها مجاناً وبسهولة فائقة على **GitHub Pages**:

### الخطوة الأولى: إنشاء مستودع جديد على GitHub
1. ادخل إلى حسابك على [GitHub](https://github.com/) واضغط على **New Repository**.
2. سمِّ المستودع باسم من اختيارك، مثلاً: `al-raed-math-platform` أو `math-platform`.
3. اجعل المستودع **Public** ثم اضغط **Create repository**.

### الخطوة الثانية: رفع الملفات إلى المستودع
افتح سطر الأوامر (Terminal أو PowerShell) في مجلد المشروع، ونفذ الأوامر التالية:

```bash
# تهيئة المستودع محلياً (تمت جاهزيته بالفعل)
git branch -M main

# ربط المستودع بمستودعك على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/<اسم-المستخدم>/<اسم-المستودع>.git

# رفع كافة الملفات
git push -u origin main
```

### الخطوة الثالثة: تفعيل GitHub Pages
1. من صفحة المستودع على GitHub، توجه إلى تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية، اختر **Pages** (الموجودة تحت قسم Code and automation).
3. عند خيار **Build and deployment**:
   - تأكد أن **Source** مضبوط على: `Deploy from a branch`.
   - تحت **Branch**، اختر: الفرع `main` والمجلد `/(root)`.
4. اضغط على زر **Save**.

🎉 **مبارك!** خلال ثوانٍ معدودة سيظهر لك رابط الموقع المباشر في أعلى الصفحة بصيغة:
`https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
